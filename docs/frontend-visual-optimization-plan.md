# 明日方舟 Agent 前端视觉优化计划

> 版本：v1.0 · 2026-07-24
> 范围：全部页面（聊天 / 管理后台 / 知识图谱）+ 全局设计系统
> 风格方向：**明日方舟「战术终端」工业风**
> 原则：**只动样式与结构，不改任何业务逻辑与 SSE 流程**

---

## 一、现状诊断

通读 `frontend/src` 全部源码后，当前界面存在四个层面的问题：

### 1.1 设计系统缺失

| 问题 | 位置 | 现状 |
|------|------|------|
| 色彩无层级 | `assets/styles.css` | 一套科技青 + 灰，无主/次/弱文字三级，无面板层级 |
| 字体误用 | 全局 | Orbitron（纯英文科幻字体）+ `text-transform: uppercase` + `letter-spacing` 套用在中文标题上，中文显示发虚、拥挤 |
| 圆角语言混乱 | 全局 | 4px / 8px / 12px / 999px 胶囊混用，无统一几何语言 |
| 无阴影体系 | 全局 | 面板全靠 1px 细边框区分层级，深色下边界模糊、缺乏纵深 |

### 1.2 图标体系混乱（三套混用）

- 字母占位符：导航用 `Q`（问答）、`G`（图谱）、`N`（新建）等单个字母当图标
- Emoji：工具卡片用 `📚`、`🌐` 等 emoji，渲染受系统影响、风格完全脱节
- 内联 SVG：部分位置有 SVG，但尺寸、线宽不统一

### 1.3 对比度与可读性差

- 工具调用卡片正文、参数值全部使用暗灰色，SSE 过程中用户最关心执行状态，反而最看不清
- 聊天正文 14px 偏灰，长文本阅读费力
- 激活态/hover 态差异微弱，会话列表当前项几乎不可辨识

### 1.4 缺乏精致感

- 空状态只有一行居中文案，无品牌感
- 动效只有简单的 fade，生硬
- 加载状态是朴素转圈或纯文字 "..."
- 弹窗、Toast 与整体深色风格不统一

### 1.5 与明日方舟 IP 零关联

科技青 + Orbitron 是"通用赛博模板"，换成任何一个 AI 聊天项目都成立，没有方舟辨识度。

## 二、设计方向：罗德岛战术终端

### 2.1 从明日方舟 UI 提取的设计语言

不直接使用任何游戏素材（版权原因），而是提取其**设计语言规则**：

| 语言要素 | 方舟 UI 特征 | 本项目落地 |
|----------|-------------|-----------|
| 工业底色 | 大面积深灰黑面板 + 白色文字 | 深色主题为主战场，4 级背景层 |
| 高饱和点缀 | 标志性警示黄 + 少量全息青 | 黄 = 主行动/激活态；青 = 信息/链接/全息元素 |
| 斜切几何 | 按钮/面板 45° 切角、平行四边形 | `clip-path` 切角替代大圆角，全局直角体系 |
| 警示条纹 | 黄黑/灰黑斜纹分隔带 | 用于空状态装饰、页眉分隔、加载条 |
| 双行标题 | 大号粗黑中文 + 小号英文标注 | 所有页面标题、区块标题统一为双行制 |
| 战术标注 | 坐标刻度、十字准星、参数小字 | 顶栏状态栏、面板角落刻度装饰 |
| 菱形元素 | 源石/合成玉菱形 | Logo、头像、加载指示、工具状态灯 |
| 等宽数字 | 参数、ID、时间戳用窄体/等宽 | JetBrains Mono / Rajdhani 处理所有数字与英文标注 |

### 2.2 设计原则（本次所有改动的评判标准）

1. **直角与切角优先**：消灭胶囊圆角，面板一律 0-2px 圆角 + 切角
2. **实色与线框，不用渐变堆砌**：仅全息光效元素允许微弱渐变
3. **三级文字对比**：主文字 #E8ECF2 / 次文字 #9AA4B2 / 标注 #5B6470，标注必须 12px + 等宽/窄体
4. **一处一个焦点色**：同一屏内黄色只出现在主行动点和激活态
5. **动效克制**：150-250ms，ease-out，位移不超过 4px

## 三、设计系统重构（Design Tokens）

重写 `assets/styles.css` 的变量层，这是所有页面优化的地基。

### 3.1 色彩 Tokens（深色主题）

```css
/* 背景层级 */
--bg-base:      #0B0E13;   /* 最底层：页面底色 */
--bg-panel:     #12161D;   /* 面板：侧边栏、卡片 */
--bg-raised:    #1A1F28;   /* 抬升：hover、输入框、弹窗 */
--bg-overlay:   #232A36;   /* 最顶层：下拉、tooltip */

/* 线条 */
--line-normal:  #2A323F;
--line-strong:  #3A4555;
--line-accent:  rgba(255,196,0,.35);  /* 激活描边 */

/* 文字 */
--text-primary:   #E8ECF2;
--text-secondary: #9AA4B2;
--text-tertiary:  #5B6470;
--text-inverse:   #0B0E13;   /* 黄色按钮上的文字 */

/* 语义色 */
--accent:        #FFC400;   /* 方舟警示黄：CTA、激活、焦点 */
--accent-dim:    rgba(255,196,0,.12);
--info:          #3ECFE0;   /* 全息青：链接、信息、知识库工具 */
--danger:        #FF5340;
--success:       #4ADE80;

/* 三工具通道配色（工具卡片、图谱图例复用） */
--tool-rag:    #3ECFE0;   /* 知识库 = 青 */
--tool-graph:  #FFC400;   /* 图谱 = 黄 */
--tool-web:    #FF7A45;   /* 网络搜索 = 橙 */
```

浅色主题同步映射：纸白 `#F2F3F5` 底、墨黑 `#16181D` 字，点缀色不变（方舟浅色界面同样是黑白灰+黄）。

### 3.2 字体系统

| 用途 | 字体 | 说明 |
|------|------|------|
| 中文/UI 正文 | `"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif` | 系统栈，零加载成本 |
| 英文/数字/标注 | `Rajdhani` 或 `Saira` | 窄体工业风，替换 Orbitron |
| 等宽（参数/ID/时间戳） | `"JetBrains Mono", Consolas, monospace` | 工具卡片参数区、代码、统计数字 |

规则：
- **移除全局 Orbitron**，中文标题禁用 `uppercase` + 大 `letter-spacing`（仅英文标注保留 0.08em 字距）
- 中文字体通过国内 CDN（如字节静态资源镜像）或自托管 woff2，避免 Google Fonts 不可达
- 标题双行制：中文 18-20px/600 + 英文标注 11px/500/大写/灰

### 3.3 几何与阴影

```css
--radius-sm: 2px;   /* 小组件 */
--radius-md: 2px;   /* 面板统一直角微圆 */

/* 切角工具类（clip-path） */
.clip-corner    /* 切右上+左下 10px：主面板、按钮 */
.clip-corner-sm /* 切角 6px：标签、chips、小按钮 */

/* 警示条纹装饰类 */
.hazard-stripes /* repeating-linear-gradient 45deg 灰黑斜纹，4px 高 */

/* 纵深 */
--shadow-panel: 0 8px 24px rgba(0,0,0,.45);
--shadow-pop:   0 16px 48px rgba(0,0,0,.6);
--glow-accent:  0 0 0 1px var(--line-accent), 0 0 16px rgba(255,196,0,.08);
```

### 3.4 图标系统（消灭三套混用）

- 方案：内联 SVG 图标组件 `AppIcon.vue`，内置 20 个左右线性图标（lucide 风格，1.5px 线宽），统一 viewBox 24、尺寸 16/20 两档
- 替换清单：
  - 导航 `Q/G/N/S/R/X` 字母 → 对话/图谱/加号/设置等线性图标
  - 工具卡片 `📚🌐` emoji → 定制三工具图标（数据库/菱形图谱/雷达），配工具主题色
  - 关闭、展开、复制、发送等散落 SVG → 统一收编
- 工具状态灯：4px 菱形（执行中脉动 / 完成实色 / 失败红色），呼应源石菱形

### 3.5 通用组件基座（新建 `components/ui/`）

为避免三个页面各自重复实现样式，先沉淀 6 个无逻辑 UI 基件：

| 组件 | 用途 |
|------|------|
| `UiPanel.vue` | 切角面板容器（带可选角标刻度装饰） |
| `UiButton.vue` | 切角按钮：primary（黄实色）/ ghost（线框）/ danger |
| `UiTag.vue` | 直角 chips 标签 |
| `UiSectionTitle.vue` | 双行标题（中文 + 英文标注 + 可选右侧刻度线） |
| `UiStatusDot.vue` | 菱形状态灯（脉动/实色/失败三态） |
| `UiEmpty.vue` | 空状态（菱形 logo + 双行文案 + 警示条纹） |

## 四、聊天主界面优化（核心战场）

文件：`views/ChatView.vue`，逐区域改造：

### 4.1 消息气泡

| 现状 | 方案 |
|------|------|
| 圆角气泡，AI/用户区分度弱 | AI 消息：面板底色 + 左侧 3px 主题色条 + 右下切角；用户消息：右对齐深灰实色块 + 左侧切角，不再用同形气泡 |
| 头像为圆形色块 | 改为**菱形**：AI 用罗德岛风格线框菱形标，用户用首字母菱形（黄边） |
| 正文 14px 偏灰 | 15px / `--text-primary` / 行高 1.75，中文阅读优化 |
| 时间戳无 | 消息 hover 显示等宽小字时间戳 |

### 4.2 工具调用卡片（体验重点）

现状是全灰文字堆叠，改为**终端参数面板**：

```
┌─ ▶ KNOWLEDGE_RETRIEVAL / 知识库检索 ─────── ● 执行中 ┐
│  query    阿米娅 技能专精材料                          │
│  top_k    5                                            │
│  ───────────────────────────────────────────          │
│  ▸ 返回 5 条结果 · 耗时 1.2s（点击展开）                │
└──────────────────────────────────────────────────────┘
```

- 顶部条：展开箭头 + 英文工具名（Rajdhani 大写）+ 中文名 + 右侧菱形状态灯
- 左侧整卡 2px 工具主题色（rag 青 / graph 黄 / web 橙），一眼区分调用通道
- 参数区：等宽字体 key-value 表格化，key 灰 value 亮
- 结果区：默认折叠为一行摘要（条数 + 耗时），点击展开完整 JSON
- 多轮调用时卡片之间用 1px 刻度分隔线串联，强化"Agent 执行轨迹"感

### 4.3 思考过程（thinking 区域）

- 现状：灰色斜体字块
- 方案：虚线边框面板 + 顶部 `REASONING / 推理过程` 标注，SSE 流式时底部带扫描线动画（1px 青色光线自上而下循环），结束后静止

### 4.4 输入区

- 现状：圆角胶囊输入框 + 圆形发送按钮
- 方案：
  - 底部"战术终端输入条"：面板抬升 + 顶部 1px 高亮线，左侧 `>` 提示符（黄色、等宽、闪烁）
  - 输入框直角、聚焦时边框变 `--line-accent` + 微弱外发光
  - 发送按钮：切角黄实色块 + 黑色箭头图标，hover 时切角加深；禁用态灰
  - 输入框上方保留模型/状态等宽小字条（如 `DEEPSEEK-V4-FLASH · ROUND 0/15`）

### 4.5 空状态（新会话首屏）

现状一行文字，改为品牌首屏：

1. 中央大号线框菱形（缓慢 8s 旋转呼吸）
2. 双行大标题：`ARKNIGHTS ASSISTANT` + 「明日方舟 智能问答终端」
3. 上下各一条警示条纹细带
4. 快捷问题区：编号制切角卡片（`01 / 干员查询`、`02 / 剧情检索`...），hover 时左侧黄条亮出 + 右移 2px

### 4.6 流式反馈

- 回答流式输出时末尾追加方块光标 `▮`（黄、530ms 闪烁），替代现在的无提示状态
- `answer_done` 后光标消失，消息底部淡入等宽小字：`3 ROUNDS · 4.2S · 2 TOOLS`

## 八、动效规范

| 场景 | 规范 |
|------|------|
| 通用过渡 | 150-250ms `cubic-bezier(.22,.9,.32,1)` |
| hover | 背景/边框变色为主，位移 ≤ 2px，禁止缩放弹跳 |
| 页面切换 | 淡入 + 上移 4px，200ms |
| 面板进场 | 切角面板 fade + 上移 4px，stagger 40ms |
| 加载态 | 菱形脉动 / 扫描线 / 方块光标三选一，禁用菊花转圈 |
| 状态灯 | 执行中 1s 脉动，完成常亮，失败红色快闪 2 次后常亮 |
| 尊重无障碍 | `prefers-reduced-motion` 时关闭扫描线与脉动 |

## 九、实施路线图

> 每阶段独立可交付、可验收；按依赖顺序执行，前一阶段是后一阶段的地基。

- **验收**：全局变量就位，基件在独立预览页渲染正确，双主题切换无 broken

### Phase 1 · 聊天主界面（1.5 天）

- 消息气泡、工具卡片终端面板化、思考区、输入条、空状态、流式光标
- 涉及：`ChatView.vue`、新增 `MessageItem.vue` / `ToolCallCard.vue` 拆分（仅结构拆分，逻辑原样搬迁）
- **验收**：SSE 全流程（thinking → 多工具并行 → 回答）视觉连贯，三种工具卡片配色正确，移动端 375px 可用

### Phase 2 · 框架层（1 天）

- 侧边栏、顶栏状态栏、AuthModal、SettingsModal、Toast
- **验收**：导航/会话管理/登录注册/设置全路径视觉统一，双主题正常

### Phase 3 · 管理后台 + 知识图谱（1 天）

- **验收**：图谱节点配色与图例一致，后台数据可读性显著提升

### Phase 4 · 打磨与走查（0.5 天）

- 动效统一、双主题对比度走查（WCAG AA：正文 ≥ 4.5:1）、移动端适配收尾、空/加载/异常三态补齐
- **验收**：全页面走查清单通过，Lighthouse 可访问性 ≥ 95

**总工作量预估：约 4.5 天。**

## 十、风险与约束

| 风险 | 应对 |
|------|------|
| 改样式时碰坏 SSE 逻辑 | 所有改动限定在 template 结构与 style，`<script setup>` 逻辑行零改动；组件拆分只做纯搬迁 |
| `clip-path` 兼容性 | 目标浏览器（Chrome/Edge 近三代）全支持；不支持时降级为直角，无功能性影响 |
| 双主题工作量翻倍 | tokens 全部走 CSS 变量，浅色主题只做变量映射，不单独写样式 |
| 字体加载失败 | 窄体/等宽字体均配置系统字体兜底栈，加载失败仅英文标注回退，不影响中文 |
| IP 版权 | 只借鉴设计语言（切角/警示条纹/配色规则），不复制任何游戏内素材、logo、立绘 |
